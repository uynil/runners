# Domain docs

## 布局

本仓库采用 single-context：
- 根目录 `GLOSSARY.md`：领域术语及定义。
- `docs/adr/`：架构决策记录。

## 阅读规则

- 探索代码前阅读 `GLOSSARY.md`，以及与当前工作相关的 ADR。
- 若以后出现 `GLOSSARY-MAP.md`，按其中索引阅读相关领域文档。
- 文件不存在时直接继续，不提前创建空文档，也不反复提示缺失。
- 由 domain-modeling 技能在实际明确术语或决策时创建文档。

## 使用规则

- 任务标题、设计、代码和测试中的领域概念沿用词汇表定义。
- 遇到缺失术语时，先判断是否适合现有领域语言，再记录需要澄清的概念。
- 若方案与现有 ADR 冲突，明确指出相关 ADR、冲突内容及重新考虑的理由。
